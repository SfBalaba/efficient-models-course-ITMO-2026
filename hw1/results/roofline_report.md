Как считались эффективные коэффициенты:
- theta_comp — медиана latency / FLOPs на линейном участке (S >= 368 & B >= 32); 1/theta = 12.0 TFLOPS;
- theta_comp (только свёртки) — Σt / ΣFLOPs свёрток по трассе S=512, B=64; 1/theta = 16.6 TFLOPS;
- theta_mem — Σt / Σбайт ReLU/MaxPool/GAP по трассе S=512, B=64; 1/theta = 777 GB/s;
- theta_launch — минимальная latency на сетке; в roofline накладных расходов нет, идеал = 0;
- theta_power — медиана средней мощности при S >= 368 & B >= 32; при S ≤ 64 — 114 W.

## Пиковая память

Модель: константа (веса + workspace cuBLAS + прочее) + вход + max по слоям (вход слоя + выход слоя + int64-индексы MaxPool).

- совпадение с замером до 0,1 %: 50 из 132 точек; модель выше замера: 0 точек;
- остаток (workspace cuDNN): до 732 MiB (S=256, B=229);
- слой пика в модели: pool1;
- equations.memory() / замер: 0.14–2.87.

- трасса S=32, B=1: пик над базой 2.33 MiB в слое conv2; conv1_out + pool_out + индексы = 0.05 MiB
- трасса S=224, B=32: пик над базой 86.75 MiB в слое pool1; conv1_out + pool_out + индексы = 85.75 MiB
- трасса S=512, B=64: пик над базой 896.00 MiB в слое pool1; conv1_out + pool_out + индексы = 896.00 MiB

## Энергия: E = P_TDP · T_real

- E_замер / (P_TDP · T): 0.16–0.87, при S >= 368 & B >= 32: 0.80–0.87;
- E_замер / (P_limit · T): при S >= 368 & B >= 32: 0.96–1.05;
- средняя мощность: 57–262 W.
